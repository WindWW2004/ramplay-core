# Contributing

Contributions, including student work, are accepted under the licenses of this
repository: MIT for software, CERN-OHL-S-2.0 for hardware, CC BY 4.0 for docs.
By opening a pull request you agree that your contribution is your own work and
is released under those licenses.

Rules that are checked in review:

- Read `RAMPLAY_SPEC.md` first. If your change differs from it, change the spec
  in the same pull request and add a line to its change log.
- Everything must be original (spec section 1.2). No code, art, fonts, names or
  file formats from commercial consoles or other fantasy consoles.
- `make all-tests` must pass.
